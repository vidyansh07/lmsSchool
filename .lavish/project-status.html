Daily work

Four flows, in plain language

Each role gets a starting point, a short path, and one sentence saying where to stop.

C

Counsellor · bring a student in

Admissions
  1. Open Admissions dashboard.
  2. Check duplicates and register the person.
  3. Select course and batch; record fee and first payment.
  4. Plan follow-ups or transfer the enrolment.
  5. Hand the enrolled student to teaching.

Stop at: academic delivery and assessment decisions.

M

Manager · run academic operations

Operations
  1. Open Manager overview.
  2. Check risk, overdue work and pending reports.
  3. Review batches, trainers and Student 360.
  4. Approve or return work and assign follow-up action.
  5. Resolve operational warnings.

Stop at: accounts, roles and system configuration.

T

Trainer · deliver assigned learning

Teaching
  1. Open Today's class.
  2. Take attendance and record the class report.
  3. Plan or complete student activities.
  4. Set and grade assigned academic work.
  5. Use My work for the queue.

Stop at: any student, batch or course not assigned to this trainer.

A

Administrator · govern the system

Administration
  1. Open Overview and Activity review.
  2. Manage users, roles, scopes and centres.
  3. Configure policy, forms, automation and communication.
  4. Manage approvals, exports and recovery.
  5. Intervene in operations only when support is needed.

Stop at: permission lock, platform config and permanent purge unless superadmin.

Development order
